# TriliumNext Linux Distro Iconpack


### Description
This repository is an Iconpack for [TriliumNext](https://github.com/TriliumNext/Trilium).

## Installation

 1. Download the `.zip` File from this repository
 2. Go to your TriliumNext UI 
 3. Create an Note and name it **Iconpacks** (optional)
 4. Rightclick the created Note and click on **Import into Note**
5. Drag the `.zip` file into the Window or click on the big button and click on the **Import** button
6. The imported files are deactivated at import, so click at the top on the slide to activate the packs
