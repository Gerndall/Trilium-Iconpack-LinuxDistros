## Installation

 1. Download the `Linux Distros.zip` file from this repository
 2. Open TriliumNext in your Browser an select the note u want to import the pack into. You can create a note named **Iconpacks** to keep your icon packs together.
 3. Rightclick that note and choose **Import into Note**
 4. Drag the `Linux Distros.zip` file into the import dialog, or use the file picker to select it.
 5. Open the imported Linux Distros note. If the pack is disabled after import, use the activation switch at the top to enable it.

Menu Label may differ depending on your TriliumNext version and interface language.


## Using the icons
Open the icon picker for a note and search for a distro name, such as debian, kali or cachy and select the icon you want to use.

The pack uses the `ld` prefix. Examples of full icon classes:
- ld ld-Linux

## Troubleshooting
- check that you imported `Linux Distros.zip`, rather than the repository ZIP or an individual JSON File.
- Open the imported **Linux Distros** not and check if the pack needs activation.
- Check that the imported note has the iconPack label with the value ld and the LinuxDistros.woff attachment. Both are included in the supplied archive.
- Try a search term listed in manifest.json, such as ubuntu or cachy.
